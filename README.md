# Teneda Farm — V10.1 GitHub Pages Demo

واجهة عربية تفاعلية لنظام قرار ومتابعة مزرعة تنيدة.

## التشغيل
- افتح `index.html` محليًا أو انشر المستودع عبر GitHub Pages.
- البيانات المحلية تُحفظ في `localStorage` داخل المتصفح.
- لا تضع أي API key داخل المستودع العام.

## الوحدات
- الرئيسية
- خطة الحقول
- المياه والطاقة
- التمويل والعائد
- التنبؤ 2026–2048
- السجل المحاسبي
- الموقع والتنفيذ
- خطة الاستثمار

## ملاحظة AI
الواجهة تحتوي على طبقة Advisory/AI اختيارية. إذا لم يتم ضبط Endpoint خارجي، تعمل التوصيات المحلية/الاحتياطية ولا تدّعي أنها خرجت من نموذج خارجي.

## GitHub Pages
ملف `.github/workflows/pages.yml` ينشر الموقع تلقائيًا عند الدفع إلى `main`.
